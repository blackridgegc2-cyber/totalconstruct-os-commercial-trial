# TotalConstruct OS Commercial — V1 Training & Website Handoff Gate

## Completion standard
V1 is not considered fully packaged until the production UI is frozen, the Training Project is isolated from production rollups, the interactive Learning Center is validated, the final narrated system demo is recorded against that frozen UI, and the permanent production portal is ready to link from blackridgegc.com.

## Interactive Training Project
The Training Project must provide a safe sandbox and a persistent **Training & Tutorials** entry point. Lessons must open the actual TotalConstruct module so the user learns the same UI used in production.

Required lesson coverage:
1. Getting Started / dashboard / project switching / search / roles
2. Project setup, staffing, permissions and standards
3. Drawings, upload, revision control and source references
4. RFIs: add, edit, route, respond, preview, issue, track, close
5. Submittals: register, packages, review routing, status and close
6. Contracts and buyout
7. Change management and change orders
8. Financials, budgets, commitments, invoices, retainage and owner pay apps
9. Schedule, activities, milestones and impacts
10. Daily reports and meeting minutes
11. Safety, quality, inspections and punch
12. Documents, transmittals and professional publishing
13. Closeout, turnover and warranties
14. Administration, users and permissions

## Instructional behavior
Every applicable lesson should explain or demonstrate: navigate; add/create; required fields; edit/revise; attach/upload; completeness validation; preview; issue/send; approval/rejection; status tracking; search/filter; print/export; and delete/void/archive where permissions allow.

Each lesson should expose **Open this section**, **Try it in Training**, and **Next lesson**. Training data must never affect live project/company financial KPIs, production WIP, executive rollups or real external transmissions.

## Full narrated demo
Record only after final production UI freeze. The full demo follows a realistic commercial project lifecycle:
Project setup → preconstruction → buyout → construction administration → field operations → financial management → closeout.

Provide chapter links/timestamps corresponding to the interactive lessons. Where practical, include short module-specific clips in addition to the full demo. Final media is embedded/linked from the Learning Center.

## Role guidance
Training must identify relevant workflows for Executive/Admin, PM/APM, Superintendent, Accounting, Owner, Architect/Engineer, Subcontractor and Lender roles without exposing functions the active role cannot use.

## Professional document training
Training must use the production document workflow:
Select document → complete visible professional form → guided completeness check → preview → issue/send/print → track → close/archive.
Issued examples must preserve immutable snapshots, branding, exact source references and progression history.

## Final acceptance
Before website handoff verify desktop and mobile: authenticated login; Executive dashboard; project drill-in; navigation; professional forms; save/reopen; drawings; financials; schedule; Training isolation; Learning Center links; no dead instructional controls; and no startup freeze.

## Website handoff
After production acceptance, prepare a permanent branded portal target (preferred: `portal.blackridgegc.com`) with HTTPS and production authentication. The Blackridge GoDaddy website should link to that permanent portal using a clear **TotalConstruct OS Login** / **Client & Team Login** entry. Do not use a temporary Vercel preview URL for the public website link.
